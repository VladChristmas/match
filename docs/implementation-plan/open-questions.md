## Решённые владельцем
- Клиент: Tauri + React + TS (Rust/MSVC установить) — **решено**.
- Сервер: Python/FastAPI (удобный и не затратный) — **решено**.
- Модели: облачные free LLM + локальный Ollama — **решено**.
- Интеграция: vision-агент (видит экран, не парсит сайт) — **решено**.
- Психопрофиль собеседника: только пользователю; агент пишет в стиле пользователя — **решено**.
- Данные: без персональных данных, доступ по токенам — **решено**.
- Репозиторий: публичный `match` — **решено**.
- Метрики релиза: задаются динамически через кабинет суперадмина — **решено**.
- OQ-1. Vision-слой: **Windows.Graphics.Capture** — **решено**.
- OQ-5. Автономия на старте: **авто-отправка** (пользователь наблюдает) — **решено**.
