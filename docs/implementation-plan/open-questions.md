# Открытые вопросы

## Решённые владельцем
- Клиент: Tauri + React + TS (Rust/MSVC установить) — **решено**.
- Сервер: Python/FastAPI (удобный и не затратный) — **решено**.
- Модели: облачные free LLM + локальный Ollama — **решено**.
- Интеграция: vision-агент (видит экран, не парсит сайт) — **решено**.
- Психопрофиль собеседника: только пользователю; агент пишет в стиле пользователя — **решено**.
- Данные: без персональных данных, доступ по токенам — **решено**.
- Репозиторий: публичный `match` — **решено**.
- Метрики релиза: задаются динамически через кабинет суперадмина — **решено**.
- OQ-1. Vision-слой: **Windows.Graphics.Capture** — **решено**.
- OQ-5. Автономия на старте: **авто-отправка** (пользователь наблюдает) — **решено**.
- OQ-8. Модель/частота/приватность vision-анализа: **локальная `qwen3.5:9b` по умолчанию**, облако opt-in, троттлинг `MATCH_VISION_MIN_INTERVAL_SECONDS` — **решено** (ADR-0023).
- OQ-2. Бесплатные облачные LLM и порядок провайдеров: **пресеты `groq`/`gemini`/`openrouter`/`cerebras`**, порядок `openai,ollama,echo`, политика лимитов — **решено** (ADR-0024).
- OQ-4. Окружение MSVC: **остаёмся на `scripts/dev-env.ps1`** (dot-source), полная регистрация в vswhere опциональна — **решено** (ADR-0025).

## Открытые
Нет — все продуктовые вопросы (OQ-2..OQ-8) закрыты. Ниже — журнал решений.

Новые вопросы предложенного слоя поведения (`docs/architecture/agent-intelligence-layer.md`,
этапы 23–26) — **открыты, код не начат**:

| ID | Вопрос | Влияние |
|---|---|---|
| OQ-9 | **Пороги уверенности и эскалации.** Какие числовые значения используются: порог уверенности для autonome доставки, порог неопределённости для перевода в `VERIFY`, вес риск-сигналов при «стоп-факторе», коэффициенты снижения уверенности при пропуске данных. Определяются на воспроизводимом наборе тестовых сценариев, а не назначаются произвольно. | Этапы 23, 26 |
| OQ-10 | **Где живёт память.** Память живёт **локально на клиенте** в SQLite `match.db` (таблицы `memories` / `memory_events`), а не на сервере PostgreSQL. Сервер хранит только решения (`agent_decisions`) и временные оценки. Клиентская память не синхронизируется с сервером в Этапе 24; синхронизация — вне релиза. Оффлайн-очередь (Этап 20) не дублирует записи памяти. | Этап 24 |
| OQ-11 | **Временные ряды динамики отношений.** Как хранятся сигналы (`relationship_signals`): измерение (взаимность, последовательность, эмоциональный комфорт, совместимость ожиданий, способность договариваться, развитие знакомства), значение, источник/доказательство, временная метка. Политика устаревания сигналов (хранить последние N недель / скользящее окно), как сравнивать периоды и достаточно ли данных для вывода об изменении. | Этап 25 |
| OQ-12 | **Бюджеты автономности.** Какие пределы задаются пользователем: максимум сообщений за период, окна активности, перечень знакомств с автономностью, список действий, всегда требующих подтверждения, авто-остановка при повторяющихся ошибках, глобальная пауза. Какие значения по умолчанию и правила автоматического возврата к более свободному режиму (по явным правилам, а не по решению модели). | Этап 26 |
