Статус: отметки обновлены 2026-10-25 (сессия аудита релиза). Отмечено то, что
подтверждено запуском на этом окружении (скрипты/тесты/боевой PostgreSQL); всё

## Безопасность
- [x] Токен доступа хранится только локально на клиенте; не логируется (`app/api/deps.py`; логи запросов содержат метод/путь/статус/`rid`, не заголовки).
- [x] Все маршруты `/api/v1/*` требуют токен; доступ к объектам — по владельцу (защита от IDOR; тесты изоляции в `test_agent/test_decision/test_vision/test_dynamics/test_privacy`).
- [x] Входящие сообщения считаются недоверенным вводом; защита от prompt injection (fencing `<<<untrusted data>>>` + детект утечки, этап 28; adversarial-тест `test_hostile_import_cannot_change_permissions`).
- [x] Прямые действия модели запрещены: только через очередь `agent_actions` с проверкой Decision Loop и бюджета.
- [x] Инструменты модели ограничены allowlist (ADR-0006) — фактически инструментов нет вовсе: провайдеры LLM возвращают только текст.

## Приватность
- [x] Психопрофиль собеседника виден только пользователю (ADR-0005) — всех данных пользователя доступны только владельцу, психпрофиль отдельным API не выводится.
- [x] Персональные данные не собираются сверх созданных пользователем (ADR-0007; экспорт редактирует `token_ref`).
- [x] `GET /api/v1/privacy/export` отдаёт полный экспорт (14 разделов; проверено тестом и живым smoke).
- [x] `POST /api/v1/privacy/deletion-request` удаляет все данные пользователя (проверено тестом и живым smoke; кнопка доступна на экране «Приватность»).
- [x] Токены площадок не хранятся и не запрашиваются (интеграции `unsupported`, ADR-0014).
