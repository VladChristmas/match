# Release Acceptance Checklist — MATCH 0.1.0

Дата: 2026-10-25 (обновлено 2026-10-26, сессия 10 — проверка установки из
инсталлятора). HEAD на момент проверки: `68d6377`. Статусы: ПРОЙДЕНО /
ЧАСТИЧНО / НЕ ПРОВЕРЕНО — только по фактическим результатам проверок.

## 1. Установка и первый запуск — ПРОЙДЕНО
- Сборка: `pnpm tauri build` → `nsis\MATCH_0.1.0_x64-setup.exe` (2.18 МиБ),
  `msi\MATCH_0.1.0_x64_en-US.msi` (3.01 МиБ) — ПРОЙДЕНО.
- Первый запуск: БД `match.db` создаётся и мигрирует до v4; баннер
  «токен не задан» + переход в настройки — ПРОЙДЕНО (по коду и `pnpm build`).
- Установка на чистой машине и запуск из установщика — ПРОЙДЕНО в режиме
  эмуляции чистого профиля (2026-10-26): предыдущей установки в реестре нет,
  пользовательские данные `%APPDATA%/com.match.desktop` предварительно удалены
  (бэкап сохранён). Тихая установка NSIS `/S /D=...` — exit 0; запись в реестре
  (`MATCH 0.1.0` → `uninstall.exe`) и ярлык в Start Menu созданы; запуск
  `match-desktop.exe` — окно «MATCH», RSS ~32 МБ; первый запуск создаёт
  `match.db` (8 таблиц, схема идентична эталону, включая каскад
  `memory_events`); тихая деинсталляция — exit 0, каталог и запись реестра
  удалены, ярлык удалён, `match.db` по дизайну сохраняется (runbook §8).
  SHA256 installer/msi зафиксированы. Остаётся непроверенным: запуск на машине
  без предустановленных WebView2 и VC++ рантаймов (деплой-предпосылки Tauri).
- Установка поверх предыдущей версии (NSIS, `/S` в тестовый каталог) и
  последующее удаление — ПРОЙДЕНО (2026-10-25): повторный запуск установщика
  не ломает файлы и удаление штатно убирает каталог; данные папки приложения
  не затрагиваются.

## 5. Персонализация — ЧАСТИЧНО
Профиль стиля реально влияет на промпт и границы длины (`test_dialogue.py`);
качество на живой модели офлайн не оценивалось (дефолт `echo`).

## 6. Долгосрочная память — ПРОЙДЕНО (в рамках принятой модели)
Локально на устройстве (OQ-10): экран «Память» + команды `memory_*`; cargo-тесты
жизненного цикла и каскада событий; серверную память не реализуем по ADR-0030.

## 7. Разрешение противоречий — ЧАСТИЧНО
Статусы/правка/подтверждение воспоминаний и корректировка уверенности есть;
автоматический resolver противоречий между воспоминаниями не реализован —
управление пользователем (документировано).

## 8. Психологические гипотезы — НЕ РЕАЛИЗОВАНО (вне текущего релиза)
Модуля психопрофиля нет; безопасность перекрыта `trust`/`decision` стоп-факторами.
Документировано как ограничение релиза.

## 16. Работа без сети — ЧАСТИЧНО
Таймаут 20 с + abort + автоповтор + outbox (≤10 попыток, причины в журнале) —
по коду/сборке; сценарий с реальным обрывом сети не выполнялся.

## 17. Синхронизация данных — ПРОЙДЕНО (модель «сервер — авторитет»)
Клиент читает с сервера; локальные таблицы — копия/очередь; конфликтов записи
нет, так как локальные изменения не перезаписывают серверные.
