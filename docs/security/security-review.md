# Обзор безопасности

## Угрозы и меры

| Область | Риск | Мера |
|---|---|---|
| Prompt injection | входящее сообщение пытается управлять агентом | входящий текст = недоверенный ввод; LLM по строгим сценариям; allowlist инструментов; анализ ≠ разрешение |
| Автономность | несанкционированные действия | централизованный policy-engine, уровни A/B/C, лимиты, idempotency_key |
| IDOR / изоляция | доступ к чужим данным | проверка прав на каждый объект, изоляция по пользователю/токену |
| Секреты | утечка ключей | секреты не в репозитории и не в логах; хранение средствами ОС |
| Vision-слой | скрытая передача данных площадке | обработка локально; без сетевых обращений к площадке; минимизация |
| Приватность | сбор персональных данных | персональные данные не собираются; доступ по токенам |
| Психология | вред от «диагнозов» | только пользователю; confidence + срок + пересмотр; UI-ограничения |
| Логи | утечка содержимого переписки | в тех-логи не пишется полный текст |

## Аутентификация / авторизация
- Безопасная авторизация, управление и отзыв сессий, лимит попыток входа.
- Минимальные привилегии сервисных аккаунтов; отдельные права фоновых задач.
- Секреты отсутствуют в клиентском коде.

## Хранение и передача
- Шифрование при передаче (TLS), защищённое хранение чувствительных данных.
- Резервное копирование и восстановление документированы.
- Экспорт и удаление данных пользователя.

## Журналирование
- Значимые действия и причины решений; целостность журнала; понятная пользователю история.

## Правовое
- Персональные данные не собираются. При изменении этой политики — пересмотр требований (в т.ч. GDPR).
- Условия площадок знакомств периодически перепроверяются перед любым активным адаптером.
