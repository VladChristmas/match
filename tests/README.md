# tests/

Уровни тестирования.

- `unit/` — правила автономности, расчёты, лимиты.
- `integration/` — API + БД, авторизация, изоляция.
- `contract/` — интерфейсы адаптеров и схема API.
- `e2e/` — сквозные пользовательские сценарии.
- `security/` — IDOR, обход разрешений, prompt injection.
- `evaluation/` — качество психологического анализа на обезличенных сценариях.
