# modules/

Доменные модули (изолированные границы бизнес-логики).

- `user-profile/` — профиль пользователя и профиль общения.
- `psychology/` — наблюдения и гипотезы (с источником, датой, уверенностью).
- `dialogue/` — построение контекста, стратегия, генерация и проверка ответа.
- `trust/` — сигналы риска, мошенничество, давление.
- `compatibility/` — совместимость, взаимность, конфликты.
- `integrations/` — реестр адаптеров и их возможностей.
- `llm-gateway/` — единый слой доступа к моделям.
- `memory/` — память с источниками и сроками.
- `audit-log/` — журнал значимых действий и причин решений.
