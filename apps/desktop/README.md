# MATCH — Windows-клиент

Десктопный клиент (Tauri 2 + React 19 + TypeScript + Vite). Реализует интерфейс Этапа 5:
профиль, знакомства/диалоги, анализ, автономность и журнал. Общается с FastAPI-сервисом
(`services/api`) по REST с токен-авторизацией (`Authorization: Bearer`, ADR-0010).

## Экраны

| Раздел | Что делает |
|---|---|
| Профиль | Цели, ценности, границы и профиль общения (стиль, тон, юмор, инициатива) |
| Знакомства | Список разговоров, создание, импорт сообщений, генерация черновиков |
| Анализ | Оценка совместимости и риска, история оценок |
| Автономность | Режим по умолчанию (авто-отправка / черновик / ручной / пауза) |
| Журнал | Обратная связь и локальный журнал действий |
| Настройки | Адрес API, токен, проверка соединения, сведения о приложении |

## Запуск

Rust/Tauri требует загрузки MSVC-окружения (VS BuildTools 2022 не зарегистрирован в `vswhere`):

```powershell
. .\scripts\dev-env.ps1        # из корня репозитория, импортирует vcvars64
cd apps\desktop
pnpm install
pnpm tauri dev                 # или: pnpm dev  (только веб-часть в браузере)
```

## Проверки

```powershell
pnpm build                                     # tsc + vite build (типы и сборка фронтенда)
cargo check --manifest-path src-tauri\Cargo.toml   # проверка Rust/Tauri (нужен vcvars)
```

## Структура

```
src/
  components/ui.tsx     общие UI-примитивы
  context/AppContext.tsx  настройки, API-клиент, журнал
  lib/api.ts            типизированный клиент REST API
  lib/types.ts          типы, повторяющие схемы backend
  lib/settings.ts       хранение настроек (Tauri config-dir или localStorage)
  views/                экраны приложения
src-tauri/              оболочка Tauri: команды settings/app_info
```

## Заметки

- Черновики возвращаются сервером, но не отправляются: прямые действия — только за пользователем
  (Этап 8 добавит очередь и авто-отправку).
- Режим автономности разговора задаётся при создании; серверное управление (pause/resume)
  появится на Этапе 8.
